How to run this

01

Intuition over notation. Vectors are arrows, matrices transform them, the gradient points uphill — hold the picture, drop to code when symbols blur.

02

It's arrays, calculus, and probability, tied by optimization. Nearly all of ML is minimizing a loss over arrays, guided by probability.

03

Shapes are types. (m,n)@(n,p)=(m,p) — the inner dims must match. This one rule explains most deep-learning bugs.

04

The learning rate is the first knob. Because training IS stepping down a surface, step size is the first thing to change when it misbehaves.

05

Statistics keeps you honest. Error bars, no leakage, a clean held-out test — a metric without these is a vibe, not a result.

06

Rhythm: ~3 hrs/day × 3 days. Run every snippet; watching a gradient-descent loop converge beats any equation.
