How to run this

01

Lean on the familiar. ~70% of Rust is TypeScript with different syntax — types, generics, pattern matching, async. Move fast through it.

02

Respect ownership. The other ~30% (ownership, borrowing, lifetimes) is genuinely new. Do every exercise in that week; don't skim.

03

The compiler is a reviewer. Read borrow-checker errors slowly — they name the fix. Stop fighting it and it becomes a pair programmer.

04

Don't clone past errors. When a move/borrow error hits, ask 'who owns this, who just looks?' — not 'how do I .clone() past it?'

05

Errors are values. No null, no exceptions — Option and Result with ?. It's what you wish TS errors were.

06

Rhythm: ~3 hrs/day × 5 days. End each day with something that compiles and runs — cargo makes the loop fast.
