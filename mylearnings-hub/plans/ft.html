Before you start

What you should already know — shore up any gaps first:

  • Python, comfortable with LLMs (prompting + the LLM chapter)
  • Deep Learning basics (the training loop)
  • RAG and Agents context is useful
  • A GPU (local or cloud) to actually run the exercises

What you'll be able to do

By the end of this plan — the payoff, week by week:

  • WEEK 01 · The decision, the map & the dataYou can tell when to fine-tune and have a clean, split dataset.
  • WEEK 02 · SFT with QLoRAA QLoRA-fine-tuned model and a real feel for the knobs.

How to run this

01

Try the cheaper levers first. Prompt, then RAG, then fine-tune. Most teams who think they need fine-tuning don't — learn to tell.

02

Knowledge → RAG; behaviour/style → fine-tune. Never fine-tune to inject facts; it goes stale and hallucinates. Tune skills and format, retrieve knowledge.

03

The dataset is the product. A few hundred clean, consistent examples beat thousands of noisy ones. Fix the data before the epochs.

04

QLoRA + SFT is the default. A tiny swappable adapter on a 4-bit base, one GPU, no catastrophic forgetting. Full fine-tuning is a last resort.

05

Prove it beats base + best prompt. With no general-ability regression, or don't ship it — and re-check as base models improve.

06

Rhythm: ~4 hrs/day × 3 days. Every run through the same eval harness — fine-tuning is iterative, and vibes aren't a metric.
