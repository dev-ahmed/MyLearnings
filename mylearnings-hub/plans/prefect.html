What you'll be able to do

By the end of this plan — the payoff, week by week:

  • WEEK 01 · Flows, tasks, retries & concurrencyYour scripts run as flows with retries, logs and parallel steps you can see in the UI.
  • WEEK 02 · Caching, states, deployments & configYour pipelines resume cheaply after failure and run on schedules without you.

How to run this

01

Start from a script you already have. Decorate a real job first. Prefect is at its best when it wraps code that already works.

02

One task = one retryable step. If a failure would make you re-run it on its own, it's a task. Everything else is a plain function.

03

Cache what costs money. LLM calls, embeddings and big downloads get INPUTS + TASK_SOURCE caching from day one.

04

Read the run page. Task graph, logs, states and artifacts answer most questions before you open the code.

05

Break it on purpose. Make tasks fail, time out and hit limits. Watching retries and caching work is the whole lesson.

06

Rhythm: ~1.5 hrs × 4 sessions a week: read, build twice, then break and fix.
