How to run this

01

Earn the loop. Most tasks are a single call or a fixed pipeline. Build a true agent only when the path can't be pre-scripted because it depends on results.

02

The model plans; your code acts. Tools are least-privilege and validated; the model never executes anything itself, and never a destructive action unguarded.

03

Structured output for anything code reads. Decisions come from schema'd fields, never from parsing the model's prose. Prose is only for the human.

04

Bound and observe everything. A step limit, a token/time budget, and a full per-step log — before the first real run.

05

Untrusted in, guarded actions out. Assume prompt injection in every tool output; make safety architectural, not a polite instruction.

06

Rhythm: ~4 hrs/day × 3 days. Build the loop by hand before touching a framework — you can't supervise magic you've never written.
