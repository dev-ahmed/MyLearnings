How to run this

01

Build, don't watch. ~45 min reading the relevant book part, then 2–3 hrs building. Every day ends with code that runs.

02

One project, all 8 weeks. The Tasks/Projects API grows each week — new layer, same app — so nothing is throwaway.

03

Types on from day one. Keep mypy and ruff green. It's the TypeScript rigor you already have, in Python.

04

Commit daily. Small git commits, a real README. Your repo history becomes the portfolio.

05

Don't tutorial-hop. Follow this book end-to-end. Reach for other docs only when you hit a real wall.

06

Rhythm: ~4 hrs/day × 5 days, one rest day. Read errors, don't fear them — the traceback names the fix.
