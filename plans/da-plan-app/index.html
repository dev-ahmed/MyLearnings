How to run this

01

Frame the question first. The exact metric, the segment, the comparison — before any code. Most bad analyses answer the wrong question well.

02

Cleaning is the job. Raw data is read-only; every fix is reproducible code. It's most of the work and where wrong answers are born.

03

Averages lie; segment everything. Watch shapes and tails, not just means. A flat aggregate often hides two opposite trends.

04

Attach a caveat to every number. A confidence interval or sample size — and never confuse correlation with causation.

05

The LLM writes the query; the database owns the answer. Only trust numbers computed by running code, never ones a model states.

06

Rhythm: ~4 hrs/day × 3 days, always against a real dataset. This is a hands-on craft — you learn it by wrangling, not reading.
