How to run this

01

One app, six weeks. Grow a single Projects/Tasks API — language, then framework, then production — so nothing is throwaway.

02

Map every concept to Node. For each topic ask: what do I do in Express/Prisma, how is it done here, why is it different? The cookbook answers all three.

03

Types on from day one. declare(strict_types=1) + Larastan — the TypeScript rigor you already have, in PHP.

04

Lean on conventions. Laravel does a lot for you (route model binding, Form Requests, Eloquent). Learn the drawers, don't fight them.

05

Thin controllers. Validation in Form Requests, authorization in Policies, shape in Resources, logic in Actions when it grows.

06

Rhythm: ~4 hrs/day × 5 days. End each day with a route you can hit or a test that passes.
