How to run this

01

It's Node under the hood. n8n runs on Node/TypeScript and every Code node is real JavaScript. When the visual nodes don't fit, you write code — you're never stuck.

02

Think in items. Data flows between nodes as a list of JSON items. Once that clicks, expressions and the Code node stop being mysterious.

03

A workflow is a program. Triggers, branches, error handling, secrets, and deploys all apply — treat it with the same rigor as an Express service, not as a toy.

04

Reach for the Code node last, not first. Try the built-in nodes and expressions before writing JS; the point of n8n is to write less glue, not more.

05

Self-host it properly. The default SQLite + single process is a demo. Real use means Postgres, a volume, an encryption key, and queue mode.

06

Know when NOT to. High-throughput, latency-critical, or logic-heavy work still belongs in code (your Queues cookbook). n8n wins on glue, integrations, and speed of change.

07

Rhythm: ~4 hrs/day × 3 days a week. End each session with a workflow that executes green — n8n's instant-run loop makes that easy.
