How to run this

01

Not everything needs deep learning. Tabular data → gradient boosting; small data → simpler models. Always train the simple baseline first.

02

Own the training loop. zero_grad → forward → loss → backward → step, every iteration. PyTorch hands you the loop on purpose — learn it, don't hide it.

03

Watch two loss curves. Train + validation together diagnose overfitting, underfitting, and bad learning rates at a glance.

04

Transfer learning is the default. Start from a pretrained backbone and match its preprocessing — that's how real DL gets done on modest data.

05

Ship the state_dict, in eval mode, with no_grad. Save weights, recreate the model, and never forget model.eval().

06

Rhythm: ~4 hrs/day × 3 days. Run every snippet; deep learning is muscle memory. Overfit one batch before every real run.
